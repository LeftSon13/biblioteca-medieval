O QUE ESTAMOS APRENDENDO

Um catálogo simples,
com relações entre entidades.

A proposta é exercitar o que vimos em aula organizando livros, categorias, detalhes e autores em um banco PostgreSQL.

01

Livro

O registro principal do acervo.

  • Título
  • Preço e quantidade
  • Um detalhe por livro
02

Categoria

Ajuda a organizar os volumes.

  • Uma categoria pode reunir vários livros
03

Autores

Relacionamento entre livros e pessoas autoras.

  • Um livro pode ter vários autores
  • Um autor pode escrever vários livros
04

CRUD da API

Operações para praticar a comunicação web.

  • Cadastrar e listar
  • Atualizar e excluir

PARA TESTAR O BACKEND COMPLETO

Abra a biblioteca
no seu computador.

GitHub Pages publica esta apresentação e uma prévia visual com dados fictícios. Para gravar dados e testar o CRUD, rode o PostgreSQL e o Spring Boot localmente.

  1. 01
    Instale os requisitos

    Java 21 e Docker Desktop com Docker Compose.

  2. 02
    Inicie o PostgreSQL

    Na pasta do projeto, rode docker compose up -d.

  3. 03
    Inicie a aplicação

    Rode .\mvnw.cmd spring-boot:run no Windows.

  4. 04
    Explore e teste

    Abra http://localhost:8080 e importe a coleção Postman do repositório.

Sobre esta demonstração: os exemplos da prévia são fictícios e não são salvos. O banco real é local e iniciado pelo Docker.
